# PWA আইকন — জেনারেট করা ফাইল

এই ফোল্ডারের সব PNG **আসল আইকন** (আর প্লেসহোল্ডার নয়) — `node scripts/gen-icons.mjs`
favicon.svg-এর ডিজাইন (গ্রেডিয়েন্ট + fc গ্লিফ) থেকে Playwright দিয়ে জেনারেট করা।

| ফাইল | সাইজ | ব্যবহার |
|---|---|---|
| `icon-192.png` | 192×192 | PWA আইকন, নোটিফিকেশন আইকন/ব্যাজ |
| `icon-512.png` | 512×512 | PWA আইকন / স্প্ল্যাশ |
| `icon-maskable-192.png` | 192×192 | অ্যান্ড্রয়েড অ্যাডাপটিভ (সেফ-জোনে গ্লিফ) |
| `icon-maskable-512.png` | 512×512 | অ্যান্ড্রয়েড অ্যাডাপটিভ |
| `apple-touch-icon.png` | 180×180 | iOS হোম-স্ক্রিন (opaque) |

রিজেনারেট: `cd frontend && node scripts/gen-icons.mjs`
