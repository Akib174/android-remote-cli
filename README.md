# fcfc 🚀

**সম্পূর্ণ এন্ড-টু-এন্ড এনক্রিপ্টেড, রিয়েল-টাইম, ইনস্টলযোগ্য (PWA) চ্যাট অ্যাপ্লিকেশন** — টেলিগ্রাম/সিগন্যাল-অনুপ্রাণিত ডিজাইন, ফ্রেমার মোশন অ্যানিমেশন, ক্লাউডফ্লেয়ারের সম্পূর্ণ ইকোসিস্টেমে তৈরি।

> ## 🆕🆕 সর্বশেষ আপডেট — রাউন্ড ১৪ (UX-রাউন্ড)
>
> **🎭 একক-ইমোজি রিডিজাইন**
> - কুইক-লাইক/একক-ইমোজিতে এখন **একই Apple artwork ইমোজি** থাকে (আগের "অন্য রকম" অ্যানিমেটেড webp বাদ) — **ঠিক একবার** bounce হয়ে থেমে যায়
> - ইমোজিতে **ক্লিক করলে উভয় পাশে** আবার ১-বার প্লে হয় (রিয়েল-টাইম `emoji-replay` ইভেন্ট)
>
> **📌 Saved Messages — আসল Telegram-স্টাইল**
> - 🍔 মেনু থেকে সরাসরি খোলে/তৈরি হয়; নিজেকে লিখুন, যেকোনো চ্যাট থেকে **ফরওয়ার্ড** করে সেভ করুন
> - নীল বুকমার্ক-অ্যাভাটার + লিস্টে সবার উপরে; E2EE, রিলোড/নতুন ডিভাইসেও হিস্ট্রি ফেরে
>
> **🐛 গ্রুপ-ডিলিট সাদা-স্ক্রিন ফিক্স** — খোলা চ্যাট/গ্রুপ ডিলিট করলে এখন নিরাপদে লিস্টে ফেরে (আগে পুরো স্ক্রিন সাদা হয়ে যেত)
>
> **🎬 আরও Telegram-অনুভূতি**
> - প্রোফাইল-প্যানেল smooth **width-reveal** অ্যানিমেশন (মোবাইলে স্লাইড), মেম্বার-লিস্ট stagger, চ্যাট-সুইচ ট্রানজিশন
> - হালকা গ্লাসমরফিজম — সেটিংস-প্যানেল ও মডাল-কার্ডে (মেসেজ-বাবল সলিডই — পড়া সহজ)
>
> **📱 মোবাইল-টাইপিং**
> - Android-এ কীবোর্ডের নিচে সেন্ড-বাটন চাপা পড়ে না (`interactive-widget=resizes-content`); iOS-এ visualViewport-সিঙ্ক + ১৬px ফন্ট (অটো-জুম বন্ধ)
> - লম্বা টেক্সটে ইনপুটের ভেতরেই স্ক্রল-বার; safe-area সাপোর্ট
>
> **👥 New Group-এ কন্টাক্ট অটো-লোড** — খুললেই কন্টাক্ট দেখা যায়, সার্চও কাজ করে • **🗑️ Wallet-অপশন রিমুভ**

> ## 🆕 আগের আপডেট — Telegram-রেফারেন্স ফিক্স রাউন্ড
>
> **🍔 হ্যামবার্গার মেনু (Telegram হুবহু)**
> - ⚙️ গিয়ারের বদলে ☰ মেনু — অ্যাকাউন্ট-হেডার, Add Account, My Profile, Saved Messages, Contacts, Wallet, Settings, More (Night Mode / Archived / Log Out সাব-মেনুসহ)
>
> **🖱️ মেসেজ-মেনু ও রিয়্যাকশন**
> - রাইট-ক্লিক মেনু Telegram-ক্রমে: Reply → Copy Text → Pin → Forward → Edit/Star → Delete (লাল)
> - রিয়্যাকশন-স্ট্রিপ Telegram-এর ৭টা ইমোজি (👍😢❤️👎🔥😂👏) + chevron → **গ্রিডে** সব ইমোজি এখন দেখা যায় (আগে এক লাইনে স্ক্রিনের বাইরে চলে যেত — "ড্রপডাউনে ইমোজি দেখা যায় না" বাগ)
> - hover-অ্যাকশন বার (Reply/React/Edit/More) এখন **শুধু কার্সর মেসেজের পাশে আনলে** অ্যানিমেট হয়ে দেখা যায় — আগে সবসময় দেখা যাচ্ছিল (framer-motion inline-opacity বাগ)
>
> **✓✓ টিক**
> - ১ টিক = sent/delivered, ২ টিক (নীল) = seen — Telegram-এর মতোই
>
> **😀 একক-ইমোজি**
> - অ্যানিমেশন **একবার** চলে থেমে যায়; ইমোজিতে **ক্লিক** করলে আবার প্লে
> - 🐛 CDN-এ 128px artwork নেই (404) — এখন সব সাইজে 64px artwork (আপস্কেল)
> - 🐛 সোলো-ইমোজিতে ছোট + বড় দুটো ইমোজি একসাথে রেন্ডার হতো — এখন শুধু বড়টা
>
> **📞 কল — স্ট্যান্ডার্ড UI + ৪টা ফিক্স**
> - ⏱️ **টাইমার কল অ্যাকসেপ্ট হলেই শুরু** — আগে ওভারলে খোলার সাথেই চলত; এখন রিং-স্টেটে "Ringing…", কানেক্ট হলে কাউন্ট-আপ
> - 🎥 **ভিডিও-কলে ভিডিও এখন দেখা যায়** — আগে setTimeout-রেসে srcObject হারাত (state-চালিত করা হয়েছে)
> - 🖥️ **স্ক্রিনশেয়ার মেইন-স্টেজে বড় করে দেখায়** (ক্যামেরা ছোট প্রিভিউতে) — শেয়ার-স্টেট সব পার্টিসিপ্যান্টের কাছে সিঙ্ক হয়
> - 📞 **কল-হিস্ট্রি চ্যাটে দেখা যায়**: "Outgoing Video Call (1 minute, 7 seconds)" / "Incoming Call (…)" / "Canceled Call" / "Missed Call" (লাল) — Telegram-এর সার্ভিস-পিল স্টাইলে
>
> **🔎 সার্চ (Enter-ছাড়া)**
> - টাইপ করার সাথে সাথে সাইডবারেই ইউজার-রেজাল্ট ভেসে ওঠে — ক্লিক করলেই চ্যাট/প্রোফাইল খোলে
>
> **🔐 নতুন-ডিভাইসে মেসেজ-হারানো ফিক্স**
> - ১:১ মেসেজ এখন **নিজের কী-তে এনক্রিপ্ট করা self-copy সহ** সার্ভারে জমা হয় — নতুন ডিভাইসে লগইন দিলেও নিজের পুরো হিস্ট্রি ফেরত আসে (আগে নিজের পাঠানো অনেক মেসেজ উধাও হতো)
> - কী-ব্যাকআপে এখন ৩০০০ পর্যন্ত ডিক্রিপ্টেড মেসেজ-ক্যাশ থাকে (আগে ৮০০)
>
> **👥 গ্রুপ-ডুপ্লিকেট ফিক্স**
> - একই নামে গ্রুপ আবার বানালে নতুন না বানিয়ে **পুরনোটাই খোলে** (সার্ভার-সাইড dedupe + ডাবল-সাবমিট গার্ড)
>
> **🪟 সাইডবার**
> - ড্র্যাগ করে একদম ন্যূনতমে (শুধু প্রোফাইল/অ্যাভাটার-রেল) — আগের মতোই, ESC-সহ মেনু হ্যান্ডলিং উন্নত

> ## 🆕 আগের ভার্সনে যা যোগ/ঠিক হলো
>
> **🔐 সাইনআপ ও সার্চ**
> - সাইনআপে **মোবাইল নম্বর (বাধ্যতামূলক)** + **ইমেইল (ঐচ্ছিক)**; সেটিংস → প্রোফাইল থেকে পরেও যোগ/বদলানো যায়
> - অন্যরা আপনাকে **ইউজারনেম / ফোন / ইমেইল — বা একসাথে সব টোকেন দিয়েও** খুঁজে পাবে
>
> **😀 ইমোজি**
> - একক-ইমোজি মেসেজ এখন **৫x বড় + টেলিগ্রাম-অ্যানিমেটেড** ([Tarikul-Islam-Anik/Telegram-Animated-Emojis](https://github.com/Tarikul-Islam-Anik/Telegram-Animated-Emojis) — ৮৪৮টি ম্যাপিং, অ্যানিমেশন না থাকলে স্ট্যাটিক Apple artwork-ই ৫x)
>
> **🎤 ভয়েস ও 📞 কল — 🔴🔵 দুই মোড**
> - মাইকে হোভার/ক্লিক → 🔴 **লাল** (ওপাশে ভয়েস **অটো-প্লে** — অন্য চ্যাটে থাকলেও) বা 🔵 **নীল** (সাধারণ)
> - ফোন-আইকনে হোভার/ক্লিক → 🔴 **লাল** (ওপাশে **অটো-অ্যান্সার**) বা 🔵 **নীল** (সাধারণ রিং)
>
> **💬 মেসেজিং**
> - মেসেজ-টেক্সট এখন **সিলেক্টেবল** (আগে বন্ধ ছিল)
> - মেসেজে হোভার করলেই **অ্যাকশন-বার**: রিপ্লাই / ইমোজি-রিয়্যাকশন / এডিট / ৩-ডট মেনু (ফরওয়ার্ড, ডিলিট-মি, ডিলিট-এভরিওন, পিন, স্টার) — রাইট-ক্লিক কনটেক্সট মেনু আগের মতোই আছে
> - রিসিট-টিক (✓/✓✓) এখন **বড় ও স্পষ্ট**
>
> **🎨 UI/UX**
> - ইমোজি ও ক্লিপ আইকনে **হোভার করলেই** পপওভার খোলে, কার্সর সরালে বন্ধ
> - সাইডবার এখন **ড্র্যাগ-রিসাইজযোগ্য** (৬৮px পর্যন্ত সরু — শুধু অ্যাভাটারের কমপ্যাক্ট-মোড; ডাবল-ক্লিকে রিসেট)
> - সাইডবার **গ্লাসমরফিজম + ডান-কোণা কার্ভড** — পেছনের ওয়ালপেপার দেখা যায়; চ্যাট-হেডার ও ডান প্রোফাইল-প্যানেল কম্পোজারের মতো **কার্ভড ফ্লোটিং গ্লাস**
> - লগইন/সাইনআপ পেজে **কোণায় লাইট/ডার্ক টগল** + স্মুথ ট্রানজিশন; পুরো অ্যাপে স্প্রিং-অ্যানিমেশন
> - `@date` লিখলে **মিনি-ক্যালেন্ডার** — তারিখ বাছলে `dd/mm/yyyy` বসে যায়
>
> **🧡 Messenger-স্টাইল লাইক-বাটন**
> - কম্পোজারের ডানে-কোণে সবসময় থাকে; ট্যাপে ইনস্ট্যান্ট পাঠায়, লংপ্রেসে বদলানো যায়
> - গ্লোবাল ডিফল্ট (সেটিংস → প্রোফাইল) + **প্রতি-চ্যাট ওভাররাইড** (সেই চ্যাটের প্রোফাইল-প্যানেল থেকে)
>
> **🔗 গ্রুপ**
> - **ওয়ান-টাইম ইনভাইট লিংক** — এখন গ্রুপ-প্রোফাইল প্যানেল থেকেই জেনারেট/কপি/ডিলিট; একবার ব্যবহারেই মৃত
> - 🐛 **গ্রুপ-বাগ ফিক্স:** নতুন খালি গ্রুপ/চ্যাট আগে লিস্টেই দেখা যেত না (`deleted_before`-ফিল্টারে `0≥0` সত্য হতো) — এখন ঠিক
> - 🐛 **সাইলেন্ট-সকেট ফিক্স:** হাব-সকেট নীরবে মরে গিয়ে লাইভ-ইভেন্ট আটকে যেত — এখন hb-ack/ping-pong **ওয়াচডগ** নিজে থেকেই রিকানেক্ট করে + ৬০-সেকেন্ড সেফটি-নেট পোল
>
> **🎮 গ্রুপ-কলে গেম-মোড**
> - কলে থাকা মেম্বারদের বেছে **টিম** বানানো যায় → সবাই **Enter** চাপলে টিম অ্যাকটিভ — শুধু নিজের টিমের অডিও শোনা যায় (২v২ গেমিংয়ের জন্য); ডিসিলেক্ট, টিম-সুইচ, এক্সিট সব আছে

> ⚡ **ডিপ্লয় এক কমান্ডে:** টোকেন বানিয়ে (My Profile → API Tokens → **"Edit Cloudflare Workers"** টেমপ্লেট + এডিট করে **D1:Edit** ও **Workers R2 Storage:Edit** পারমিশন যোগ করে):
> ```bash
> export CLOUDFLARE_API_TOKEN="আপনার-টোকেন"   # Windows PS: $env:CLOUDFLARE_API_TOKEN="..."
> node deploy.mjs
> ```
> D1/KV/R2, মাইগ্রেশন, সিক্রেট, বিল্ড, ডিপ্লয় — সব অটো, অ্যাপ+API একটাই URL-এ। বিস্তারিত: [`DEPLOYMENT-GUIDE.md`](./DEPLOYMENT-GUIDE.md)-এর "দ্রুততম উপায়" অংশ।
>
> 🆕 **একদম নতুন?** প্রতিটি কমান্ড ও ক্লিক সহ ধাপে ধাপে গাইড: **[`DEPLOYMENT-GUIDE.md`](./DEPLOYMENT-GUIDE.md)**

                                    │   │    রিয়েল-টাইম রিলে, টাইপিং, রিসিট,    │
                                    │   │    ডিলিট-ভ্যানিশ ব্রডকাস্ট, কল স্টেট      │
                                    │   └─ UserHub   (প্রতি ইউজারে ১টি)         │
                                    │        প্রেজেন্স + পুশ ফ্যানআউট             │
                                    └────────────┬─────────────────────────────┘
                              ┌──────────────┬───┴───┬───────────────┐
                              │      D1      │  KV   │      R2       │
                              │ ইউজার/চ্যাট   │ রেট-  │ এনক্রিপ্টেড মিডিয়া│
                              │ মেটাডেটা/কী   │ লিমিট │  (2GB/ফাইল)    │
                              └──────────────┴───────┴───────────────┘
```

### 🔐 এনক্রিপশন মডেল (Signal-অনুপ্রাণিত)
- প্রতি ইউজার: **Identity Key (X25519)** + সাইনড প্রিকি + ২০টি ওয়ান-টাইম প্রিকি — ক্লায়েন্টে জেনারেট হয়, প্রাইভেট কী কখনো সার্ভারে যায় না।
- **X3DH**-এর মতো প্রাথমিক হ্যান্ডশেক → **Double Ratchet** (প্রতি মেসেজে আলাদা কী, ফরওয়ার্ড সিক্রেসি)।
- গ্রুপে **Sender Keys**: প্রতি মেম্বারের চেইন-কী ১:১ এনক্রিপ্টেড চ্যানেলে বিতরণ হয়; নতুন মেম্বার জয়েন করলে জেনেসিস-কী শেয়ার হয় বলে সে **আগের হিস্টোরিও** পড়তে পারে।
- ফাইল/মিডিয়া আপলোডের **আগে** ক্লায়েন্টে এনক্রিপ্ট হয় (১-মিলিয়ন-বাইট চাঙ্ক, কী মেসেজ-পেলোডে)।
- **কী-ব্যাকআপ**: পাসওয়ার্ড থেকে ডেরাইভ করা কী (PBKDF2 ৬০০k) দিয়ে প্রাইভেট কী বান্ডিল এনক্রিপ্ট করে সার্ভারে থাকে — পাসওয়ার্ড ছাড়া ডিক্রিপ্ট অসম্ভব।
- পাসওয়ার্ড সার্ভারে হ্যাশড অবস্থায় থাকে। **কোনো রিকভারি নেই** — পাসওয়ার্ড ভুলে গেলে অ্যাকাউন্ট চিরতরে অ্যাক্সেসযোগ্য নয় (এটাই প্রাইভেসির দাম)।

## 🚀 ডিপ্লয়মেন্ট গাইড (ধাপে ধাপে)

### পূর্বশর্ত
- [নোড ≥ 18](https://nodejs.org), [Cloudflare অ্যাকাউন্ট](https://dash.cloudflare.com) (ফ্রি প্ল্যানেই চলবে), `npm i -g wrangler` ও `wrangler login`

### ১. ব্যাকএন্ড রিসোর্স তৈরি

```bash
cd worker
npm install

wrangler d1 create fcfc-db            # → যে database_id পাবেন
wrangler kv namespace create KV       # → যে id পাবেন
wrangler r2 bucket create fcfc-media
```

`wrangler.toml`-এ `database_id` ও KV `id` বসান। তারপর মাইগ্রেশন:

```bash
wrangler d1 migrations apply fcfc-db          # প্রোডাকশন
wrangler d1 migrations apply fcfc-db --local  # লোকাল টেস্ট
```

### ২. সিক্রেট সেট করুন

```bash
npm run vapid                          # VAPID কী জেনারেট করে দেখাবে
wrangler secret put JWT_SECRET         # যেকোনো লম্বা র‍্যান্ডম স্ট্রিং
wrangler secret put REFRESH_PEPPER
wrangler secret put VAPID_PUBLIC_KEY   # জেনারেটরের আউটপুট (৮৮ অক্ষরের পয়েন্ট)
wrangler secret put VAPID_PRIVATE_KEY
wrangler secret put PUSH_CONTACT       # যেমন: mailto:you@example.com
wrangler secret put CALLS_API_TOKEN    # Cloudflare Calls API টোকেন (কল না চালালে বাদ দেওয়া যায়)
```

সাথে `worker/wrangler.toml`-এর `[vars]` সেকশনে SFU অ্যাপের **App ID** বসান:
```toml
CALLS_APP_ID = "your-serverless-sfu-app-id"   # Realtime → Serverless SFU থেকে
```

### ৩. ওয়ার্কার ডিপ্লয়

```bash
wrangler deploy
# → https://fcfc-backend.<your-subdomain>.workers.dev — এটাই আপনার API বেস (ডোমেইন কোথাও হার্ডকোড নেই)
```

### ৪. ফ্রন্টএন্ড সেটআপ + ডিপ্লয়

```bash
cd ../frontend
npm install
cp .env.example .env                   # VITE_API_BASE=https://fcfc-backend.<your-subdomain>.workers.dev
npm run build                          # dist/ তৈরি হবে
wrangler pages project create fcfc     # (প্রথমবার)
wrangler pages deploy dist --project-name=fcfc
```

### ৫. কাস্টম ডোমেইন যুক্ত করা (ঐচ্ছিক)

1. **ওয়ার্কার**: ড্যাশবোর্ড → `fcfc-backend` → Settings → Domains & Routes → আপনার ডোমেইনের একটি সাবডোমেইন যোগ করুন (যেমন `api.আপনার-ডোমেইন`)।
2. **পেজেস**: `fcfc` প্রজেক্ট → Custom domains → মূল ডোমেইন বা `app.আপনার-ডোমেইন` যোগ করুন।
3. ফ্রন্টএন্ডের `.env`-এ `VITE_API_BASE=https://api.আপনার-ডোমেইন` দিয়ে আবার `npm run build && wrangler pages deploy dist`।
4. (রেকমেন্ডেড) ওয়ার্কারের `src/index.ts`-এর CORS হেডার `access-control-allow-origin: *` সরিয়ে শুধু আপনার ফ্রন্টএন্ড অরিজিন দিন।

> ডোমেইন নাম কোডে কোথাও হার্ডকোড করা নেই — শুধু `.env` আর ড্যাশবোর্ড সেটিং বদলালেই যেকোনো ডোমেইনে চলবে।

### ৬. লোকাল ডেভেলপমেন্ট

```bash
# টার্মিনাল ১ — ব্যাকএন্ড (worker/.dev.vars ফাইলে সিক্রেট কপি করুন)
cd worker && cp .dev.vars.example .dev.vars && npm run dev

# টার্মিনাল ২ — ফ্রন্টএন্ড
cd frontend && printf 'VITE_API_BASE=http://localhost:8787\n' > .env && npm run dev
```

## 📞 Cloudflare Calls সেটআপ (ভিডিও/ভয়েস কল)

1. ড্যাশবোর্ড → **Realtime → Serverless SFU** → আপনার অ্যাপ → **App ID** কপি করুন।
2. **App Secret** নিন — অ্যাপ **বানানোর সময়ে** একবার দেখানো ৬৪-অক্ষরের Secret (⚠ অ্যাপের ভেতরের "Create API Token" টোকেন **নয়** — SFU শুধু App Secret নেয়; Secret হারালে নতুন অ্যাপ বানান)।
3. `worker/wrangler.toml`-এ `CALLS_APP_ID = "..."` + `wrangler secret put CALLS_API_TOKEN` দিয়ে সেট করুন
   (দ্রুততম পথ: `CALLS_APP_ID="আইডি" CALLS_API_TOKEN="অ্যাপ-সিক্রেট" node deploy.mjs`)।
4. বাকিটা কোড হ্যান্ডেল করে: ওয়ার্কার `/apps/{appId}/sessions/new` ও `tracks/new` নেগোসিয়েশন প্রক্সি করে (টোকেন ক্লায়েন্টে কখনো যায় না); প্রতি পার্টিসিপ্যান্ট নিজের সেশন বানিয়ে রিমোট ট্র্যাক pull করে। গ্রুপ কল, স্ক্রিন শেয়ার ও মিড-কল জয়েন সাপোর্টেড।

## 🔔 পুশ নোটিফিকেশন

- সেটিংস → নোটিফিকেশন → "চালু করুন" (ব্রাউজার পারমিশন লাগবে)।
- অ্যাপ বন্ধ থাকলেও সার্ভিস ওয়ার্কার পুশ ধরে নোটিফিকেশন ট্রে-তে দেখায় (সাউন্ড ডিভাইস-নির্ভর; ইন-অ্যাপ পিং সাউন্ড সবসময় বাজে)।
- নতুন ডিভাইসে লগইনের খবরও পুশ আকারে যায় — পুশে ক্লিক করলে সরাসরি ডিভাইস-লিস্ট (Decline করার জায়গা)।

## ⚠️ সীমাবদ্ধতা / নোট

- ≤১০০ ইউজার স্কেলের জন্য ডিজাইন করা; আর্কিটেকচার প্র্যাকটিকাল রাখা হয়েছে।
- ওয়ার্কার রানটাইমে নেটিভ আর্গোন২ নেই বলে **PBKDF2-SHA256 (৬০০k)** ব্যবহৃত — চাইলে `worker/src/lib/password.ts`-এ WASM-আর্গোন২ বসানো যায় (ইন্টারফেস একই)।
- টোকেন `localStorage`-এ থাকে (স্ট্যান্ডার্ড SPA প্যাটার্ন); চাইলে `localStorage`-এ এনক্রিপ্টেড রাখা যায়।
- 2GB ফাইল এনক্রিপশন ব্রাউজার মেমোরিতে হয় — বড় ফাইলে যথেষ্ট র‍্যাম থাকা ডিভাইসে সুপারিশকৃত।
- ব্রাউজার `X25519` WebCrypto সাপোর্ট করে (আধুনিক ক্রোম/এজ/ফায়ারফক্স/সাফারি)।
